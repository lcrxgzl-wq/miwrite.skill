# 文本精读质量标准

## 核心目标

精读输出应帮助读者理解一篇文章"怎么做的"和"我能从中学到什么"，而非简单概括"讲了什么"。

## 必检项（不通过则整体不合格）

1. **范式诊断存在且有依据**：给出了研究范式判断，并引用了文中具体段落作为依据
2. **论证结构被显式化**：核心论点、子论点和证据类型被拆解出来，不是模糊概括
3. **所有判断有原文锚点**：每个分析点附 [p.N] 页码引用，读者可以回到原文验证
4. **区分描述与评价**：明确标出哪些是"作者说了什么"，哪些是"精读者的分析判断"
5. **质疑点有理由**：不能只说"有待商榷"，必须给出具体的质疑逻辑

## 优选项

1. 论证地图清晰（核心论点 → 子论点 → 证据链）
2. 可借鉴点具体到"怎么借鉴"（不只是"值得学习"）
3. 跨文本比较（当精读多篇时，指出方法论或论证策略的差异）
4. 方法论分析到位（不只看理论和结论）
5. 行文风格和写作技巧被显式点出

## 常见失败

1. **读书报告式输出**：只概括每节内容，没有结构和方法论分析
2. **脱离原文发挥**：用精读者自己的知识替代原文论证，输出了原文不包含的观点
3. **全面肯定**：回避文章薄弱环节，输出像推荐语而非分析
4. **缺少锚点**：分析判断没有引用具体页码或段落，无法验证
5. **维度偏科**：只分析理论维度，忽略方法论和写作结构
