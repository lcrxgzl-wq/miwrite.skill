# 文本精读方法论指南

## 核心目标

把一篇学术文本拆解为可被研究者借鉴的结构化知识，包括：范式诊断、论证结构、理论脉络、方法论特征、可借鉴点和值得质疑处。

## 精读不是摘要

精读的输出不是"这篇文章讲了什么"，而是"这篇文章怎么做的、为什么这样做、我能从中学到什么"。

| 摘要式（不要） | 精读式（要） |
|---------------|------------|
| 本文研究了社区治理问题 | 本文用"制度嵌入日常"框架处理社区治理，核心张力是正式制度与非正式协商的冲突 |
| 作者使用了质性方法 | 作者选择个案比较而非单案例，因为需要控制区域差异；但比较维度的选取理由偏弱 |
| 文章有五个部分 | 引言用问题链（现象→困惑→缺口→本文贡献）在一页内完成，这种密度适合短篇期刊论文 |

## 精读五步

### 第一步：范式诊断

判断文章属于哪种研究范式，这决定了后续拆解的维度。

- 实证-归纳型：从田野材料中提炼概念
- 理论-演绎型：用现有理论框架解释新现象
- 批判-解构型：质疑既有概念或方法的预设
- 综合-建构型：整合多个理论传统提出新框架

输出要求：给出范式判断 + 判断依据（引用文中具体段落）。

### 第二步：论证结构拆解

把文章的论证链条显式化。

- 核心论点是什么？（一句话）
- 论点由哪些子论点支撑？
- 每个子论点的证据是什么类型？（经验数据 / 文献引用 / 逻辑推演 / 类比）
- 论证链条中是否有跳跃？（结论超出证据支撑范围）

输出格式：论证地图（核心论点 → 子论点1[证据类型] → 子论点2[证据类型] → ...）

### 第三步：理论脉络追溯

- 文章对话的理论传统是什么？
- 作者如何定位自己与前人的关系？（继承/修正/挑战/综合）
- 关键概念的定义是原创还是借用？如果借用，是否有改造？

### 第四步：方法论特征

- 研究设计选择的理由是什么？
- 数据来源和收集方式是否匹配研究问题？
- 分析策略是否透明？（能否从文中复现分析步骤）
- 方法论局限是否被作者承认？

### 第五步：可借鉴点与质疑点

- 有哪些写作技巧值得借鉴？（结构、表达、论证策略）
- 有哪些理论洞见可以迁移到读者自己的研究？
- 有哪些薄弱环节值得质疑或进一步追问？

## 输出规范

1. 每个判断必须附原文锚点 [p.N]
2. 区分"作者说了什么"和"我认为作者做得怎样"
3. 不要用"本文很好地..."这类空泛评价
4. 可借鉴点要具体到"怎么借鉴"，不要只说"值得学习"
5. 质疑点要给出质疑理由，不要只说"有待商榷"

## 常见错误

1. 把精读做成读书报告（只概括内容，不分析方法和结构）
2. 脱离文本发挥（用自己的知识替代原文论证）
3. 只夸不批（回避文章的薄弱环节）
4. 维度遗漏（只看理论，忽略方法论；或只看结论，忽略论证过程）
