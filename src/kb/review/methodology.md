# 稿件评阅方法论指南

## 核心目标

模拟严格但建设性的同行评审，帮助作者在投稿前发现和修复硬伤。不假装替代真实评审，只聚焦可检测的结构性问题。

## 评审不是校对

| 校对式（不要） | 评审式（要） |
|---------------|------------|
| 第三段有错别字 | 引言的问题意识和第四节的经验解释之间存在跳跃——概念定义不支撑后续分析 |
| 参考文献格式不统一 | 文献综述覆盖了三个传统但没有交代为什么选这三个，读者无法判断遗漏 |
| 建议润色语言 | P0：核心论点在摘要和结论中的表述不一致，需要统一 |

## 评审维度（按优先级）

### P0：论证硬伤（必须修复，否则无法发表）

- **问题意识不成立**：研究问题不清晰、已被充分回答、或不构成学术贡献
- **核心论点不一致**：摘要、引言和结论中的核心论点表述矛盾
- **证据不支撑结论**：结论超出数据/材料的支撑范围
- **方法论与问题不匹配**：研究设计无法回答研究问题
- **概念定义缺失或循环**：关键概念未定义，或用概念解释概念

### P1：结构问题（显著影响可读性和说服力）

- **文献综述与正文脱节**：综述了理论但正文没有使用
- **章节逻辑断裂**：各节之间的推进关系不清晰
- **材料呈现无序**：经验材料的组织没有分析逻辑
- **讨论节空转**：讨论节只是重复发现，没有理论对话

### P2：细节问题（影响规范性但不致命）

- **引用不充分**：关键论断缺少文献支撑
- **术语不一致**：同一概念在不同位置用不同名称
- **写作冗余**：可以压缩的重复表述
- **格式不规范**：图表标注、参考文献格式等

## 评审输出规范

### 问题分级

每个问题标注优先级 P0/P1/P2，附具体位置 [p.N] 或 [para.N]。

### 修订建议

每个问题给出具体的修订方向（不是"建议修改"，而是"建议在第三节开头补充从X到Y的过渡逻辑"）。

### 修订路线图

根据问题数量和严重程度，给出修订时间建议：
- 90 分钟路线：只修 P0，确保论证链条完整
- 半天路线：修 P0 + P1，提升结构和说服力
- 不限时：全面修订

## 不同稿件阶段的评审侧重

| 稿件阶段 | 侧重 |
|---------|------|
| 开题报告 | 问题意识是否成立、文献覆盖是否充分、方法论可行性 |
| 论文初稿 | 全维度评审，重点 P0 硬伤 |
| 修改稿 | 上轮问题是否修复、新增内容是否引入新问题 |
| 定稿前 | 一致性检查（摘要/引言/结论对齐）、格式规范 |

## 评审纪律

1. **只评你能看到的**：不要基于你对该领域的知识补充作者没写的内容
2. **区分"不好"和"不同"**：作者的方法论选择可能与你的偏好不同，不等于错误
3. **给理由**：每个批评必须附具体理由和原文依据
4. **不要替作者写**：指出问题和方向，不要替作者重写段落
5. **承认不确定性**：如果你不确定某处是否有问题，标注为"建议作者确认"而非"必须修改"

## 常见错误

1. **事无巨细**：在 P2 细节上花太多篇幅，P0 硬伤一笔带过
2. **只批不建**：指出问题但不给修订方向
3. **越权评审**：对文章的研究选题本身发表意见（"不应该研究这个"）
4. **风格偏好强加**：把自己的写作习惯当作规范要求
5. **忽略优点**：只挑毛病，不确认文章做得好的部分（评审也需要正面反馈）
