# 稿件评阅质量标准

## 核心目标

评阅输出应帮助作者定位硬伤并获得可执行的修订方向，而非泛泛地说"有待改进"。

## 必检项（不通过则整体不合格）

1. **问题分级存在**：每个问题标注 P0/P1/P2，不能所有问题平级罗列
2. **问题有定位**：每个问题附 [p.N] 或 [para.N] 位置引用
3. **修订建议具体**：不能只说"建议修改"，必须给出方向（"补充从X到Y的过渡"）
4. **区分了批评与偏好**：不把风格偏好当作规范错误
5. **P0 问题不遗漏**：如果论证链条有明显断裂，必须被标出

## 优选项

1. 给出修订时间路线（90分钟/半天/不限时）
2. 确认了文章做得好的部分（不只挑毛病）
3. 问题按维度分组（论证/结构/方法/表达），不是流水账
4. 不确定处标注"建议作者确认"
5. 修改稿对照了上轮问题是否修复

## 常见失败

1. **P0/P1/P2 不分**：所有问题平级罗列，作者无法判断优先级
2. **只批不建**：指出"第三节有问题"但不说怎么改
3. **越权**：评价研究选题本身（"不应该研究这个"），而非评价论文质量
4. **校对式输出**：大量篇幅花在错别字和格式上，忽略论证硬伤
5. **无依据批评**：批评没有引用原文具体位置
