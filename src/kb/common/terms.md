# Core Terminology

社科学术写作中英术语映射表。按领域分组，供润色/转写/综述时保持术语一致性。

## 通用方法论

| Chinese | Preferred English | Notes |
|---|---|---|
| 文献综述 | literature review | Use for review sections and standalone review papers. |
| 研究缺口 | research gap | Avoid "research blank" or "blank area". |
| 理论框架 | theoretical framework | Use consistently. |
| 作用机制 | mechanism | In causal contexts, "underlying mechanism" may fit. |
| 资料分析 | data analysis | For qualitative material, "qualitative data analysis" may be clearer. |
| 编码 | coding | In qualitative research context. |
| 开放编码 | open coding | Qualitative analysis term. |
| 轴心编码 | axial coding | Qualitative analysis term. |
| 选择性编码 | selective coding | Qualitative analysis term. |
| 访谈资料 | interview data | Avoid "interview materials" in formal academic English unless referring to documents. |
| 田野材料 | field materials / field data | Choose based on discipline and sentence context. |
| 翻译转写 | academic transcreation | Use when emphasizing adaptation beyond literal translation. |
| 扎根理论 | grounded theory | Capitalize when referring to the specific methodology. |
| 主题分析 | thematic analysis | Distinct from content analysis; do not conflate. |
| 内容分析 | content analysis | More structured/quantitative than thematic analysis. |

| 可信性 | credibility | Lincoln & Guba's term, qualitative equivalent of internal validity. |
| 可迁移性 | transferability | Qualitative equivalent of external validity. Not "generalizability" in strict qualitative contexts. |

## 翻译陷阱（高频误译）

| Chinese | Wrong Translation | Correct Translation | Why |
|---|---|---|---|
| 社会治理 | social management | social governance | "management" implies top-down control; "governance" captures multi-actor dynamics. |
| 获得感 | sense of gain | sense of achievement / perceived benefit | "gain" is too literal; use context-appropriate alternatives. |
| 网格化管理 | grid management | grid-based governance | Add "based" for clarity; this is a specific Chinese governance model. |
| 放管服 | delegate-regulate-serve | streamlining administration, delegating powers, and improving services | Official English translation exists; use it consistently. |
| 人情 | human feelings | renqing / interpersonal obligations | Keep pinyin in theoretical writing; "human feelings" loses the reciprocity dimension. |
| 面子 | face | mianzi / face | Keep pinyin when discussing the concept theoretically; "face" is acceptable in general usage. |
| 关系 | relationship | guanxi / particularistic ties | Keep pinyin when the concept carries theoretical weight beyond generic "relationship". |
| 单位 | unit | danwei / work unit | Keep pinyin for the specific Chinese institutional form; "unit" is too generic. |
| 差序格局 | differential mode of association | chaxu geju / differential order | Fei Xiaotong's concept. Keep pinyin + English gloss on first use. |
| 权威体制 | authoritative system | authoritarian system / authority structure | Distinguish based on context: value-neutral vs. critical framing. |

## Rules

- User-provided term mappings override this file.
- If multiple translations are accepted, choose one and apply it consistently throughout the document.
- Do not invent technical translations for unfamiliar terms; flag uncertainty when needed.
- For culture-specific concepts (人情, 面子, 关系, 差序格局), prefer pinyin + English gloss on first use, then pinyin only.
- When a term has discipline-specific meanings (e.g., "field" in Bourdieu vs. general usage), add context to disambiguate.
