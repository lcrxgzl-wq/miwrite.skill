# 引用验证规则

所有涉及引用的输出必须遵循以下规则：

## 引用标注

- 每条引用必须标注验证状态：`[已验证]` / `[未找到]` / `[未验证]`
- 如果引用无法在 Semantic Scholar API 中找到，标记为 `[未找到]` 并说明原因
- 如果 API 不可用，标记为 `[未验证]`

## 引用格式

- 中文文献：作者（年份）《标题》。来源。[验证状态]
- 英文文献：Author (Year). Title. Source. [验证状态]
- 页码锚点：保留 `[p.N]` 标记，与引用验证状态独立

## 反幻觉规则

- 不得编造不存在的引用
- 不得将 AI 生成的内容伪装为引用
- 如果找不到合适的引用，明确说明"原文未提供相关引用"
