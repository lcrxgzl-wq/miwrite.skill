# Local Organize

Use this skill when the user has messy local material and needs a ledger, main thread, evidence cards, or writing preparation.

Local-only contract:
- do not call hosted MCP
- do not use API keys
- do not use hosted knowledge search

Inputs:
- local material
- organizing topic
- organizing mode if available

Workflow:
1. inventory the local material set
2. group it by source, scene, time, or function
3. extract a candidate main thread and supporting evidence cards
4. keep unresolved gaps explicit

Output:
- material ledger
- main thread
- evidence cards
- contradiction and gap list
- next-step recommendation
