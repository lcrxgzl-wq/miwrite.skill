# Local Close Reading

Use this skill when the user wants to understand or interrogate a specific local text.

Local-only contract:
- do not call hosted MCP
- do not use API keys
- do not use hosted knowledge search

Inputs:
- local text
- reading route if available: map, transfer, or critique

Workflow:
1. identify the text type, argument structure, evidence chain, and limits
2. choose or confirm a close-reading route
3. produce evidence-bound reading cards from the local text
4. keep all judgments traceable to the source text

Output:
- argument map
- structure and concept notes
- evidence-chain reconstruction
- transfer or critique notes depending on the route
